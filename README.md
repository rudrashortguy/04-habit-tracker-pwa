# StreakLoop - Habit Loops & Streak Visualization

Build lasting habits with daily check-ins, heatmap contribution graphs, reminder notifications, and offline sync.

## Features
- GitHub-style contribution heatmaps
- Push notification reminders
- Streak freezing & recovery
- Weekly habit completion reports

## Tech Stack
- **Vite** & **React 18** with TypeScript
- **Tailwind CSS** for responsive mobile-first styling
- **Workbox / Vite PWA Plugin** for offline caching & service worker lifecycle

## Development
```bash
npm install
npm run dev
```
