# HabitHero PWA

Gamified daily habit tracker with streaks, badges, and offline sync.

### Features
- Streak counter
- Calendar heatmap
- Local state management
- Sound effects

### Tech Stack
- **Vite** & **TypeScript**
- **Workbox / Vite PWA Plugin** for offline capabilities
- **IndexedDB & LocalStorage** for persistent state

### Getting Started
```bash
npm install
npm run dev
```
